# 学生卡识别与透视校正（OpenCV 传统视觉）

用 **OpenCV 传统视觉**（不含深度学习）在电脑摄像头上实时识别学生卡/学生证，
并做**透视变换**把倾斜拍摄的卡片拉正为标准正面图。

> 选题 B「OpenCV 图像基础」作业项目。

---

## 效果

| 实时识别 | 透视校正结果 |
|---|---|
| 摄像头画面中绿框标出卡片，左上角红色 `ID Card` 标签 | 倾斜拍摄的四边形 → 拉正为 428×270 标准图 |

实测：**30.1 FPS**（640×480 处理分辨率），卡片长宽比 1.58~1.72
（真实证件 85.6 : 54 ≈ 1.585）。

## 技术路线

```
图像读取
  ↓
中值滤波（5×5，压制桌面/布料编织纹理产生的假边缘）
  ↓
双线索并行
  ├─ 颜色线索：BGR → HSV → inRange 颜色阈值 → 开运算去噪 → 闭运算填洞
  └─ 边缘线索：灰度 CLAHE + Canny，叠加 Lab 色彩空间 a/b 通道的色度梯度
  ↓
findContours 提取轮廓
  ↓
几何筛选（四重判据）
  · 面积占比 2%~62%
  · 矩形度（区域面积 ÷ 最小外接矩形面积）
  · 长宽比 1.10~2.20
  · 边缘支撑度（四条边上的平均梯度 / 内部平均梯度）
  ↓
两条线索的候选统一打分，取最优
  ↓
四角排序 + 自动转正（竖拍时四角顺序滚动一位）
  ↓
getPerspectiveTransform + warpPerspective → 428×270
  ↓
实时显示
```

### 与任务要求的技术点对应

| 要求 | 实现 |
|---|---|
| 图像读取 | `cv::VideoCapture` / `cv::imread` |
| 颜色过滤（HSV 阈值切分） | `cvtColor(BGR2HSV)` + `inRange`；**H 是 0~179 不是 0~360**，红色跨 0 回绕需拆成 `[0,12]` 与 `[165,179]` 两段再按位或 |
| 基础图像处理 | 中值滤波、形态学开/闭运算、Canny、CLAHE、图像位运算 |
| 仿射 / 透视变换 | `getPerspectiveTransform`（4 点，8 自由度）+ `warpPerspective` 反向重采样 |

> 对比实现过 `getAffineTransform`（3 点，6 自由度）：**仿射变换保留平行性，
> 数学上无法把梯形拉正**，所以此处必须用透视变换。

## 编译运行

依赖：OpenCV 4.x、CMake ≥ 3.16、支持 C++17 的编译器。

```bash
mkdir -p build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make
```

**摄像头实时识别：**
```bash
./lesson2_card
```
- `q` 或 `ESC` 退出
- `s` 保存当前识别结果（`shot_detect.png` / `shot_card.png`）

**单张图片识别：**
```bash
./lesson2_card 图片路径.jpg 输出前缀
# 产出 输出前缀_detect.png（带框）和 输出前缀_card.png（校正结果）
```

## 实测数据

| 指标 | 数值 |
|---|---|
| 透视校正输出 | 428×270（比例 1.585，匹配证件 85.6:54） |
| 识别到的卡片长宽比 | 1.58（静态照片）/ 1.72（手持略倾斜时） |
| 单帧处理耗时 | 6~9 ms |
| 摄像头帧率 | **30.1 FPS** |
| 矩形度判据 | 真卡片 0.86~0.96，褶皱/杂物 0.59~0.72，取 0.82 可完全分开 |
| 稳定处理宽度 | 640~800（超过 800 后纹理尺度与固定中值核失配，识别率下降） |

## 踩过的坑（都记录了原因）

1. **卡片被更大轮廓包住 → 漏检**
   举着卡拍时"人体 + 衣服"的轮廓把卡片整个套住，卡片成为子轮廓。
   `RETR_EXTERNAL` 只返回最外层，直接丢掉卡片 → 改用 `RETR_LIST`。

2. **桌面编织纹理制造大量假边缘**
   实测纹理区的相邻像素差最大可达 114，**比卡片边界的跳变（86）还大**，
   靠调高 Canny 阈值无法区分（会把卡片边一起滤掉）。
   中值滤波的判据是"变化是否**持续**"而非"变化多大"，
   因此能压掉反复跳变的纹理、保留阶跃边缘（实测纹理动态范围 72→42，阶跃边 45→45 不变）。

3. **处理分辨率不能盲目提高**
   纹理斑点的像素尺度随分辨率放大，固定 5×5 中值核失配 → 处理宽度锁在 640~800。

4. **颜色区域填充率天然偏低**
   卡面是彩色图案，绿叶/橙黄/白楼不在色域内，掩码有大量空洞。
   所以颜色线索的填充率门槛（0.60）必须低于边缘线索（0.82）。

5. **CLAHE 之后的图不能用来算梯度**
   CLAHE 会放大卡面纹理，使内部梯度虚高、边/内比被拉低，真卡片反而被否掉。
   需保留一份原始灰度专门算梯度。

6. **平面 PnP 有二义性**（做 RoboMaster 位姿时遇到，与本项目无关但同类问题）
   平面目标能解出两组姿态，必须显式去二义并看**重投影误差**。

## 已知限制与改进方向

- 手持姿态不利时（倾斜过大、手指压住卡片边缘、距离过远）会短暂丢失目标。
- 改进方向：用 **Hough 直线拟合卡片四条边求交点**（不依赖轮廓闭合，抗遮挡）、
  时序滤波与多帧投票。
